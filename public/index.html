Maintenance

Backup & restore

Protect the archive

Database backups contain account credentials and peer identity keys. Store them somewhere private. Media files remain separate; use the manifest to verify your media-folder backup.

Restore a database

Move or clone

Full instance transfer

Stream the database, uploaded media, profile images, geocodes and encrypted OAuth connections into one bundle.

Treat this bundle as sensitive. It includes account password hashes and peer identity. It does not include .env or encryption keys, so configure the same CONNECTIONS_ENCRYPTION_KEY on the destination before importing.

Export this instance
